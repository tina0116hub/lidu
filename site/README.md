# 李杜诗心 · 诗句相似度可视化

把 `李白.csv`、`杜甫.csv`、`李白-杜甫.csv` 三份原始数据整理成一个可交互的单页网站，
用来观察李白与杜甫两部诗集之间的 23,448 组诗句配对。

---

## 一、打开方式

**直接双击 `site/index.html` 即可**（数据已内嵌为 `site/data.js`，无需联网、无需本地服务器）。

若想用本地服务器预览：

```powershell
cd site
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

外层根目录的 `index.html` 只做一件事：自动跳转到 `site/index.html`。

---

## 二、页面结构

| 页面 | 内容 |
| --- | --- |
| **总览** | 数据规模 KPI、两条「诗卷」主视觉与跨卷连线、相似度直方图、四条阅读线索、最相似的 6 组诗句 |
| **相似度** | 可拖动阈值（全部 / 中位数 / 前 10% / 前 5% / 前 1%）、区间分布、累积曲线、双方覆盖视角、高分对排行 |
| **诗作网络** | 诗歌级二分网络：左侧李白、右侧杜甫，节点面积 ∝ 配对条目数；支持 60 / 120 / 200 / 全部、拖拽、缩放，点选诗作查看配对对象；附「配对最多的诗作」双榜 |
| **对照** | 句序位置散点、共同语汇（48 个共用字）、诗长与配对数（对数坐标） |
| **检索** | 按诗句、诗题、关键字检索；可限定「两侧 / 只找李白句 / 只找杜甫句」、最低相似度、排序方式，结果分页 |

交互细节：

- 任意诗句对、诗作卡片都可以点开详情弹层；弹层内可继续跳转对诗。
- 深浅色主题切换（纸 / 墨 / 夜），偏好保存在浏览器本地。
- 所有图表悬停有数值提示；窗口缩放会自动重绘。
- 支持直接链接：`index.html#network`、`index.html?theme=ink`、`index.html?open=poem&id=lb:53871`。

## 三、数据字段的辨认结果

`李白-杜甫.csv` 没有表头，共 11 列。经过与两个诗人表逐行比对，实际含义为：

| 列 | 含义 | 说明 |
| --- | --- | --- |
| 0–2 | 李白：诗人名 / 诗题 / 诗句 | 前三列固定为「李白, 诗题, 诗句」 |
| 3–5 | 杜甫：诗人名 / 诗题 / 诗句 | 后三列固定为「杜甫, 诗题, 诗句」 |
| 6 | **相似度** | 0–10000 的整数，即页面上显示的 70.0–100.0 分（**倒数第五列**） |
| 7 | 李白诗 ID | 与 `李白.csv` 第 3 列 pid 对应 |
| 8 | **李白句序** | 在该诗中的行号，从 0 起 |
| 9 | 杜甫诗 ID | 与 `杜甫.csv` 第 3 列 pid 对应 |
| 10 | **杜甫句序** | 在该诗中的行号，从 0 起 |

> 注：后四列为「李白 ID、李白句序、杜甫 ID、杜甫句序」，与直觉中的「先 ID 后句序」不同；
> 若把第 8 列当成杜甫句序，会得到 60% 以上的错配。本项目的 `build_data.py` 已按上表解析，
> 并对全部 23,448 行做了诗句文本回查，全部命中（0 条缺失、0 条错位）。

两个诗人表的结构均为 4 列：

| 列 | 含义 |
| --- | --- |
| 0 | 诗题 |
| 1 | 诗句 |
| 2 | 诗 ID（同一首诗的所有句共享） |
| 3 | 句序（从 0 起） |

数据概况：

- 李白 1,084 首 / 14,469 行 / 91,767 字；杜甫 1,462 首 / 19,347 行 / 124,043 字
- 配对 23,448 组；相似度均值 73.2、中位数 72.3、前 1% 门槛 84.0、最高 100.0（两组完全相同的句子）
- 李白 1,056 首（97.4%）进入配对，杜甫 1,428 首（97.7%）进入配对；被配上的是 1,497 个李白诗 ID——部分诗句分属不同版本或残句
- 配对条目最多的李白诗为《经乱离后天恩流夜郎忆旧游书怀赠江夏韦太守良宰》（301 组），
  杜诗为《壮游》（190 组）

## 四、文件说明

```
李杜/
├─ index.html            # 跳转入口
├─ site/
│  ├─ index.html         # 页面结构
│  ├─ styles.css         # 视觉系统（纸/墨/夜三套主题、响应式）
│  ├─ app.js             # 交互与全部 Canvas 图表
│  ├─ data-model.js      # 数据索引层（诗作、诗句、配对、字索引）
│  ├─ data.js            # 已内嵌的数据（约 2.4 MB，由脚本生成）
│  ├─ data.json          # 同一份数据的纯 JSON（供其他分析复用）
│  └─ build_data.py       # 从三份 CSV 重新生成 data.json / data.js
├─ 李白.csv
├─ 杜甫.csv
└─ 李白-杜甫.csv
```

重新生成数据（原始 CSV 更新后）：

```powershell
python site/build_data.py
```

脚本会读取上级目录的三份 CSV，输出 `site/data.json` 与 `site/data.js`，并把解析统计打印到控制台
（配对数、跳过数、相似度分位数、共同字等）。

## 五、实现说明

- 纯静态：HTML + CSS + 原生 JavaScript，不依赖任何 CDN 或图表库，离线可用。
- 图表全部用 Canvas 手绘（直方图、累积曲线、散点、对数散点、二分网络），含 DPR 适配与悬停命中检测。
- 网络视图为确定性布局（按配对条目数排序的两列 + 轻度碰撞松弛），避免力导向随机性导致每次打开形态不同。
- 数据检索在前端完成：23,448 条记录的过滤、排序、分页都在毫秒级。
- 无障碍与适配：键盘可关闭弹层（Esc）、`prefers-reduced-motion` 下关闭动画、900px / 560px 两级响应式断点。

## 六、可继续扩展的方向

- 把「相似度」与字面重合度（Jaccard、编辑距离）做相关性检验，判断这个分数究竟在衡量什么。
- 按诗体（五古 / 七律 / 绝句）、题材、创作年代分组，比较配对密度的差异。
- 将共同语汇扩展为二元组 / 意象词表（月、酒、山、水、雁……），做意象共现网络。
- 若需要展示全部 2,500 余首诗的网络，建议改用 WebGL 或服务端预计算布局。
